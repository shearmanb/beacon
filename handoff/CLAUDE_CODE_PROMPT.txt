The mock data.js shapes map to real data as follows: sites[] = config.json (id, name, enabled, strategy, schedule, imminent, intervalMinutes, imminentIntervalMinutes) merged with state.json (lastChecked, products map, checkHistory, consecutiveErrors, cooldownUntil, errorAlertSent); products[] = flattened from the products map inside each site's state entry in state.json; reveries[] = subset of products where title.toLowerCase().includes("reveries") or siteId is reveries_official or sharedpour_reveries; scheduleOptions[] = keys from schedules.json plus fixed presets "5", "15", "20", "30", "60"; reminders[] = reminders.json ({ items: [...] }); pending[] and collection[] have no current real data source — leave as placeholder tabs.
